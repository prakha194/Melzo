Support

Melzo is a one-person project. Every report is read; answers arrive on GitHub.

Get help

  • Something is broken — open an issue and say what happened.
  • An idea for the app — open an issue with the label enhancement, or comment on an existing one.
  • Extension problems — the Spotify Pro extension has its own tracker: Melzo-Extension issues.
  • A security problem — do not post it publicly. Use GitHub's private report on the repository's Security tab.

Before you report a bug

These three details make a fix possible on the first try:

  • Your phone model and Android version
  • The Melzo version — Settings → About
  • What you did, what you expected, and what happened instead

Common problems

The APK will not install

Android blocks installs from unknown sources by default. When the prompt appears, allow installs from your browser or file manager. If it still refuses, check that you have at least 100 MB free, and that you are not installing an older build over a newer one — uninstall the newer version first, or install the newest APK from the release page.

"App not installed" after downloading again

That usually means an older copy was signed differently, or the download was incomplete. Delete the file, download it again from the release page, and check it against the matching .sha256 file. If you switched from another build of the same app family, uninstall the old one first — data will be lost, so export anything you need.

Login fails or keeps asking me to sign in

Sign in on Spotify's own page, not inside a webview that blocks cookies. If it loops, clear the app's storage, then sign in again. A network that blocks Spotify's login domains — some office and campus Wi-Fi — will cause this too; try mobile data.

A song plays from Spotify even though the extension is installed

Open Settings → Playback → audio sources and drag the extension above Spotify. If it is already first, the song may simply have no match on YouTube Music — the extension falls back to Spotify on purpose.

Downloads fail or stop halfway

Downloads need a stable connection and free storage of roughly the size of the playlist. Turn off battery saver for Melzo while downloading, and check that the app is allowed to use data in the background.

The update is not showing up

Update checks run when you open the app. If you installed from an APK, make sure that build can check for updates; otherwise download the newest APK from this site and install it over the old one — settings and downloads are kept.

Where do I get the extension?

From the store inside the app: Settings → Extensions → Store, then paste https://github.com/prakha194/Melzo-Extension. Full steps are on the extension page.

Response times

Melzo is maintained in spare time. Simple questions usually get an answer within a few days; a fix takes as long as the bug deserves. Reproducible reports with a log or a screenshot move fastest.

Support the project

The best support costs nothing: use the app, report what breaks, and tell one friend who is tired of ads. If you want to give something back, the repository has a sponsor button.
