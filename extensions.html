Melzo — Spotify Pro extension

+

Version 1.0.5 · made by Prashant · free software

Melzo plays whatever your Spotify account can play. The Spotify Pro extension goes one step further: it adds YouTube Music as an audio source, so Melzo can stream and download the official recording of the song you are listening to.

This is an extension for Melzo, not a separate app. Install Melzo first, then add the extension from the store inside the app.

What it does

  • Playback — matches the title, artist and length of the song against YouTube Music's catalogue, searching in the song's own language, and streams the audio file it finds.
  • Downloads — saves the same file through Melzo, so the track stays on your phone for offline listening.
  • No match, no problem — a song it cannot match plays from Spotify exactly as before.

Install

  1. Open Melzo → Settings → Extensions → Store.
  2. Paste this address in the store and install it: https://github.com/prakha194/Melzo-Extension
  3. Go to Settings → Playback → audio sources and drag the extension above Spotify.
  4. Play any song. If a match is found, Melzo plays it from YouTube Music; otherwise it falls back to Spotify.

Permissions it asks for

Melzo shows every permission of an extension before you install it. This one asks for three:

  • Play audio from elsewhere (critical) — needed to hand a stream to the player.
  • Provide downloads (critical) — needed to save a file for offline play.
  • Use the internet — only these hosts: music.youtube.com, youtubei.googleapis.com, *.googlevideo.com.

Nothing is sent to the developer. The extension talks to YouTube Music because that is where the audio comes from.

Good to know

  • Melzo and its extensions are independent projects, not affiliated with Spotify, YouTube or Google.
  • Downloading from YouTube Music is against that service's terms. Use the extension only with content you have the right to use, and support the artists you listen to.
